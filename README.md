# ⚖️ Amal Hamad Al-Khaldi Law Firm Website

A modern, responsive legal web interface designed (UI/UX) and developed from scratch for Amal Hamad Al-Khaldi Law Firm & Legal Consultations in Jubail Industrial City.

---

## 🎨 UI/UX & Design Concept

- 100% Original Design: The entire UI/UX design was created independently from scratch, specifically tailored to reflect the prestige and professionalism of the firm.
- Color Harmony: Deep Navy (`#212b88`) and Accent Gold (`#C5A059`) for a trustworthy legal aesthetic.
- User-Centric Architecture: Clean RTL structure utilizing Google's Cairo typography for optimal Arabic readability.

---

## 🗺️ Project Development Roadmap

This repository follows a structured 3-phase development approach:

### 🎨 Phase 1: UI/UX Design & Brand Identity (Completed)
- Independent end-to-end UI/UX design creation.
- Brand identity alignment, typography, and color palette definition.
- Wireframing and layout structure.

### 💻 Phase 2: Frontend Development & Interactivity (Current - In Progress)
- Interactive Services Grid: 11-card uniform grid layout built with CSS Grid.
- Custom Modal Component: Isolated JavaScript Modal popup system replacing traditional dropdowns to avoid DOM layout shifts.
- Clean Codebase: Lightweight implementation using Semantic HTML5, CSS3, and ES6 JavaScript with zero external library dependencies.

### ⚙️ Phase 3: Backend Integration (Upcoming)
- Dynamic content & request handling using Node.js & Express.js.
- Consultation booking system & contact form processing.
- API endpoints integration for scalable performance.
